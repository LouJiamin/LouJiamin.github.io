Course overview · Computing education

Database Systems

I designed 15 course units covering relational design, SQL, storage, and transactions. Students apply these topics in a database project and explain how they tested it. The course site contains 204 interactive lesson sections, including simulations, query workbenches, and reasoning checks.

Course sequence

  1. Model the data

    Turn an equipment loan or a customer order into entities, keys, relationships, and integrity rules.

  2. Write and test SQL

    Define tables, change records, and trace the effects of joins, aggregation, subqueries, views, and access rules.

  3. Study query execution and transactions

    Follow a query through storage, indexes, and execution plans. Use transactions and competing writes to explore isolation, locking, and recovery.

  4. Build a working project

    The final workshop brings the schema, test data, queries, and validation evidence together in a project students can explain.

How I teach it

I ask students to predict what will happen to a familiar record, change one condition, and inspect the result. The same record connects the user’s view, the SQL statement, and the engine’s work.

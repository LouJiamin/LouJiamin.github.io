Ongoing study

Predicting Unaided Debugging from Multimodal Evidence

Can students’ tests and revisions during AI-assisted programming help predict how well they will debug a new problem on their own?

I collected over 6,700 AI dialogue records from 202 participants using tasks that link the dialogues to code revisions, written explanations, and screenshots. The analysis asks whether these process measures improve prediction beyond prior performance and final-answer correctness.

Illustrative assessment

Testing a SQL join with repeated enrollment records

A student asks an AI assistant to list each student enrolled in at least one course. The suggested SQL join returns one row per student in the sample because each student has only one enrollment.

Read the proposed study design

Verification behavior during assisted work

A student can check a join by changing the data, predicting the row count, and running the query again. Each step leaves different evidence about their reasoning.

Independent assessment and prediction baseline

A separate unaided task provides the outcome. I would compare predictions from prior performance and final-answer correctness with predictions that also use the student’s tests and revisions.

Initial setting and follow-up

The initial setting is database programming. A later evaluation could test whether the same indicators remain informative in web development.

Review of prediction errors

A case in which the model predicts difficulty and the student succeeds independently would help identify which behaviors it has misinterpreted.
